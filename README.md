# iMingle

A static landing page for **iMingle** — "Find Your Perfect Plus-One." A
concept site for a plus-one / companion matching service, built with Tailwind
CSS (CDN) and Phosphor Icons, with a warm, editorial visual style
(Fraunces serif + Inter).

## Preview

Open `index.html` in any browser — no build step, no dependencies.

```bash
# serve locally (optional)
python -m http.server 8000
# then open http://localhost:8000
```

## Stack

- HTML5
- Tailwind CSS (via CDN)
- Phosphor Icons
- Google Fonts (Fraunces, Inter)

## What it demonstrates

- Editorial landing-page layout with a warm, muted palette
- Tailwind config extended with custom colors, fonts and keyframe animations
- Responsive, mobile-first sections
